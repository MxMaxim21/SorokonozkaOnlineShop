# SorokonozkaApp  (WPF App)

WPF-приложение для торговой компании «Сороконожка» (магазин обуви). 
Программа позволяет клиентам просматривать каталог товаров, добавлять обувь в корзину и оформлять заказы.

## Установка

1. Клонируйте репозиторий:
   git clone [[https://github.com/MxMaxim21/NechaevMaxim_LR1.git](https://github.com/MxMaxim21/NechaevMaxim_LR1.git](https://github.com/MxMaxim21/SorokonozkaOnlineShop.git))
   cd SorokonozkaOnlineShop

2. Откройте файл решения SorokonozkaApp.sln в среде Visual Studio 2022.

3. Восстановите пакеты NuGet.

4. Развернуть скрипт БД.

5. Соберите и запустите проект (F5 или Ctrl + F5).

## Основные возможности
*   **Авторизация и регистрация:** Разграничение прав доступа (клиенты, продавцы-консультанты, администраторы).
*   **Каталог товаров:** Просмотр обуви с изображениями, отображением цены и остатков на складе.
*   **Корзина:** Добавление товаров, расчет итоговой суммы.
*   **Оформление заказов:** Сохранение заказов в базу данных с привязкой к конкретному пользователю.
*   **Администрирование:** Управление товарами.

## 📂 Структура проекта

SorokonozkaApp/
├── Entities/                # Слой работы с базой данных
│   ├── Model1.edmx          # ADO.NET Entity Data Model (схема БД)
├── Images/                  # Фото товаров
├── Models/                  # Вспомогательные классы и бизнес-логика
│   └── CartService.cs       # Сервис для управления корзиной (добавление, удаление, подсчет суммы)
├── View/                    # Пользовательский интерфейс (XAML)
│   ├── Auth/                # Окна и страницы авторизации
│   │   ├── LoginPage.xaml   # Страница входа в систему
│   │   └── RegistrationPage.xaml # Страница регистрации новых клиентов
│   └── Shop/                # Интерфейс магазина
│       ├── CartPage.xaml    # Страница оформления корзины и заказа
│       ├── EditProductWindows.xaml # Окно редактирования товара (для администратора)
│       └── ShowPage.xaml    # Главная страница с каталогом товаров
├── App.config               # Файл конфигурации (строка подключения к БД)
├── App.xaml                 # Точка входа в приложение, глобальные стили и ресурсы
├── MainWindow.xaml          # Главное окно приложения (контейнер для страниц)
└── packages.config          # Список NuGet-пакетов проекта
